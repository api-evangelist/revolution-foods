# Revolution Foods

> Revolution Foods is an Oakland, California food company founded in 2006 that manufactures and
> delivers freshly prepared, nutritious meals to K-12 schools and senior communities. It is the
> largest K-12 school meal vendor in California, serving more than 35 million meals a year across
> 800+ schools and senior centers. Certified B Corporation since 2009 and a Public Benefit
> Corporation since 2021.

## API surface

Revolution Foods publishes **no public API**. As of 2026-08-05 there is no developer portal, no API
reference, and no machine-readable specification (OpenAPI, AsyncAPI, GraphQL SDL, JSON Schema,
Postman collection, MCP manifest, or A2A agent card) on any Revolution Foods host. Probes of
`/openapi.json`, `/swagger.json`, `/api-docs`, `/graphql`, `/llms.txt`, `/.well-known/agent-card.json`
and `/.well-known/agent.json` returned 404 on `www.revolutionfoods.com` and
`centro.order.revfoods.com`; `api.`, `developer.`, `docs.`, `portal.` and `status.` subdomains do not
resolve; and there is no `revolutionfoods` GitHub organization.

Customer ordering happens through **Centro**, a login-gated web application at
`https://centro.order.revfoods.com/`, whose root redirects to `/Identity/Account/Login`. It is an
end-user portal, not a documented integration surface.
